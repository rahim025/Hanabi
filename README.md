# Hanabi Heart

Visual novel romance inspiré des anime, pensé pour Android (mobile-first, installable en PWA).

## Structure
- `index.html` : page principale + écran d'accueil
- `css/style.css` : thème et interface
- `js/main.js` : démarrage et actions du menu
- `js/core/screens.js` : gestion des écrans
- `js/core/save.js` : sauvegarde locale
- `js/data/characters.js` : personnages originaux
- `assets/` : images et sons (à venir)

## Jouer
Activer GitHub Pages (Settings → Pages → branche `main`, dossier `/root`).
Sur Android (Chrome) : menu ⋮ → « Ajouter à l'écran d'accueil ».

Orientation : paysage (manifeste `landscape` + invite à tourner l'appareil dans le navigateur).
